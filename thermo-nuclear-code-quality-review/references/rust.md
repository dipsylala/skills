# Rust

Language-specific signals for the rules in [SKILL.md](../SKILL.md). Rule numbers refer to its Rules section.

## Idiomatic, not a smell

- `unwrap()` / `expect()` in tests, examples, and on invariants the code has just established.
- Long `match` expressions over an enum the module owns; exhaustive matching is the point.

## Type and boundary escapes (rule 5)

- `unwrap()` / `expect()` on fallible input in production paths → propagate with `?` or handle the error.
- Truncating `as` numeric casts → `TryFrom` / `try_into`.
- `.clone()` added to satisfy the borrow checker where restructuring ownership would remove it.
- `unsafe` blocks without a `// SAFETY:` comment stating the invariant.
- Several `Option` or `bool` fields that together encode a state → one enum.
- `String` or `Box<dyn Error>` errors in library code → a typed error enum.
- `Box<dyn Any>` and downcasting for a known set of types.

## Branching and spaghetti (rule 2)

- The same `match` on an enum repeated across modules → a method on the enum.
- Nested `if let` chains → a single `match` or `let ... else`.
- Boolean parameters that select behaviour → an enum.

## Wrappers and magic (rule 4)

- `macro_rules!` where a function or generic would do.
- Traits with one implementation and no generic use.
- `Deref` implemented to emulate inheritance.
- Newtypes that add no invariant or meaning.

## Canonical helpers (rule 6)

- Prefer iterator adaptors, the `entry` API, and `?` over manual loops, lookup-then-insert, and hand-written `match` on `Result`.
- Use crates the workspace already depends on before adding a near-duplicate.

## Concurrency and atomicity (rule 7)

- Independent sequential `.await`s → `join!` / `try_join!` or a `JoinSet`.
- Locks held across `.await`.
- `Arc<Mutex<_>>` spreading through APIs where message passing or a single owner would simplify.
- Spawned tasks whose `JoinHandle` is dropped and whose errors are lost.

## File size and decomposition (rule 1)

- A growing `lib.rs` or `mod.rs` → split into submodules.
- Generated files exempt from rule 1: `build.rs` output and code generated by tools such as `prost`.
