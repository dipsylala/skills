# C\#

Language-specific signals for the rules in [SKILL.md](../SKILL.md). Rule numbers refer to its Rules section.

## Idiomatic, not a smell

- An `IFoo` / `Foo` pair is idiomatic when the interface is the dependency-injection or test seam. Flag it only when nothing consumes the interface.
- Framework attributes (ASP.NET Core routing and `[Authorize]`, EF Core, serializers).
- Per-file `#nullable disable` during an active nullable migration, and `partial` classes completed by generated code or source generators.

## Type and boundary escapes (rule 5)

- `dynamic`, `object` parameters, and explicit casts `(T)x` where pattern matching or a precise type fits.
- New null-forgiving `!` operators, `null!` / `default!` initializers, `#nullable disable`, or nullable `#pragma warning disable` in migrated code → nullable attributes such as `[NotNullWhen]`, or a corrected type.
- `Dictionary<string, object>` used as a data carrier → a `record` (C# 9+) or class.
- Optional parameters that encode mutually exclusive modes.
- `catch (Exception)` that swallows errors as a silent fallback (CA1031).

## Branching and spaghetti (rule 2)

- `is` / `as` type-check chains → switch expressions with patterns, or polymorphism.
- The same `switch` on an enum in several places → one mapping (switch expression or dictionary), since C# enums cannot carry behaviour.
- Boolean parameters that select behaviour → separate methods or an enum.

## Wrappers and magic (rule 4)

- Custom reflection or attribute-driven behaviour that hides control flow a direct call would show; it also blocks trimming and AOT.
- Extension methods on broad types (`object`, `string`) that encode domain rules.
- Convention-based assembly scanning that makes dependency wiring impossible to trace.
- `partial` classes used to keep a god class under the file-size limit.

## Canonical helpers (rule 6)

- Prefer LINQ, BCL guard helpers (`ArgumentNullException.ThrowIfNull`, .NET 6+), and existing project utilities over hand-rolled equivalents.

## Concurrency and atomicity (rule 7)

- `await` inside a `foreach` over independent work → `Task.WhenAll`, or `Parallel.ForEachAsync` (.NET 6+) for large sets. Each task needs its own `DbContext` (`IDbContextFactory`); EF Core does not support parallel operations on one context.
- Sync-over-async (`.Result`, `.Wait()`, `GetAwaiter().GetResult()`).
- `async void` outside event handlers, including async lambdas passed to `Action` parameters.
- `CancellationToken` accepted but not passed on (CA2016).
- Several `SaveChanges` calls for one logical operation → one `SaveChanges`, or an explicit transaction.

## File size and decomposition (rule 1)

- Several unrelated public types in one file (StyleCop SA1402).
- Generated files exempt from rule 1: `.designer.cs`, `.generated.cs`, `.g.cs`, and `.g.i.cs` suffixes; a `TemporaryGeneratedFile_` prefix; a first comment containing `<auto-generated>`; and files marked `generated_code = true` in `.editorconfig`.
