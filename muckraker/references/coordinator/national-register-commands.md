# National registers, run by you

For each company in the entity record registered in a country below (the entity, a parent, or a subsidiary), run its command before sending the agents: `python <skill folder>/scripts/mr.py <command> > "<run folder>/<cc>-<number>.jsonl"`. With a name instead of a number, the command lists candidates with their numbers. Do what the last column says, then give the file's path to the agents the table names, with the instruction in SKILL.md step 3. Each command takes a few seconds, except Norway's (about 10, since it opens each announcement), Spain's (about 30 seconds with `--empresia`, longer with a daily scan), and Luxembourg's (about 7 minutes for any number of companies in one run). Start Luxembourg's in the background and send the agents that do not take its file meanwhile; send the National registers and Financials agents only once it has finished, so their file is complete.

| Country | Command | Give the file to | Before sending the agents |
| --- | --- | --- | --- |
| France | `fr <SIREN>` (9 digits, in the LEI record) | National registers, Financials, Courts | Add the officers, and any departed officer in an `fr_officer_change`, to the entity record |
| Ireland | `ie <CRO number>` | National registers, Financials | None |
| Luxembourg | `lu <RCS number> [<RCS number> ...] --save "<run folder>/cdb-<RCS>.xml"` (give every Luxembourg group company in one run: each quarterly file is read once for all of them) | National registers, Financials, with the extract's path | Wait for it to finish before sending those two agents |
| Norway | `no <organisasjonsnummer>` | National registers, Financials, Courts; Sanctions and offshore for the `no_officer` records | Add a parent named in a `no_agreement` to the entity record |
| Finland | `fi <business ID> --fy-end <MM-DD>` | National registers, Financials, Courts | Take the year end from the facts file (leave `--fy-end` off when unknown) |
| Denmark | `dk <CVR>` (`dk "<name>"` lists companies with an LEI; or take the CVR from GLEIF's `registered_as`) | National registers, Financials; Sanctions and offshore for the `dk_officers` records | Read the `dk_notes` on subsidiaries and the parent, and any `parent_group_accounts` link, and add the group companies they name to the entity record |
| Israel | `il <company number>` (9 digits; find it in the Corporations Authority's search in a browser, by English name, as the Israel row in national-registers.md says) | National registers | None |
| Spain | `es "<registered name>" --empresia <the company's empresia.es page>` (find the page with a web search for the name and empresia; or `--pdf <BORME-A URLs>`, or `--scan-from <date> --province <INE code>` to scan each day's BORME, about two requests a day) | National registers, Financials; Sanctions and offshore for the officers and each corporate officer's representative | Add the current officers in `es_summary` to the entity record; compare the capital increases with the funding rounds in SKILL.md step 4 |
| Brazil | `br <CNPJ>` | National registers | Add a foreign partner in the QSA, usually the parent, to the entity record |

Each country's records, and which of its `<cc>_flag` records are red flags, are described under "Records from mr.py" in [national-registers.md](../sources/national-registers.md); read that country's part before SKILL.md step 4. A major flag is a red flag: quote its `quote` where it has one and cite its `url`. Three exceptions: a Danish red flag must also be confirmed on datacvr before it goes in the dossier, since the Danish data comes over plain http; an Israeli red flag must be confirmed in the Corporations Authority's own search in a browser tool and cite it, since `il` reads a copy; and a Luxembourg red flag cites the saved extract, since `verify-report` cannot open the quarterly files. Compare capital events (`fr_capital`, `no_capital`, Finland's capital notices, the `capital` changes in `es_entry` records) with the funding rounds in SKILL.md step 4. If a command fails, the National registers agent queries that register as its country row says.
