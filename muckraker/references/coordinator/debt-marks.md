# Debt and valuation marks, run by you

The script does this source's searching and reading, so an agent would mostly add cost. After sending the agents:

1. Collect the borrower names: the legal and trading names, former names, and the parent and holding company names in the entity record, plus the most distinctive single word of each (holders spell the same borrower differently).
2. Run `python <skill folder>/scripts/mr.py --user-agent "<SEC User-Agent>" marks "<name>" "<word>" ... > "<run folder>/debt-and-valuation-marks.jsonl"`.
3. Look through the records' `identifier` fields (lender rows) and `name` and `title` fields (fund holdings) for borrower names you did not search, such as a fund holding titled "<company> (<acquisition company>)". Run `marks` again only for names whose distinctive word you have not already searched (a round-1 search for "Falcon" already matched every "Falcon …" vehicle; within one run the script itself skips a name a shorter one covers), appending (`>>`) to the same file with `--skip-seen "<run folder>/debt-and-valuation-marks.jsonl"`: the script also skips a name an earlier search covered (reported as `already_searched`) and leaves out records already there (`already_seen`). One extra round is enough. Drop any name `marks` reports as `generic_alias`: it is a common word, and its results are mostly unrelated. A record with `name_mismatch` was matched only by a one-word alias and lacks the rest of the borrower's name ("Acme Growth Opportunity Corp." for "Acme Global"): check it is the borrower before using it, and leave it out otherwise.
4. Write `<run folder>/debt-and-valuation-marks.md` from the records, in the brief's report format, working through the checks in [debt-and-valuation-marks.md](../sources/debt-and-valuation-marks.md). Each red flag cites its filing URL and quotes the record's `quote`: a loan row as the page shows it, or a fund holding's name, balance, and value in the brief's XML form. Take each fund's trend, for shares or loans, from its `fund_mark_change` records. A loan's `flagged_footnotes` (non-accrual, PIK, an amendment, a default) come from the filing's own footnotes, and a fund holding's `fund_flags` (in default, interest in arrears, paid in kind) from the fund's own report, so neither needs further opening.

If the script fails (an `error` record or no output at all), send the Debt and valuation marks agent after all, telling it what you ran. A `no_holdings_found` record is a result, not a failure: no SEC-filing lender or fund holds these names, so say so in the report and cite the full-text searches in its `urls`. When it carries `partial: true`, some filings could not be read (its `unread` list, with an `error` record each): say so under Gaps, naming them.
