# Tester

First read `all-agents.md` in this folder.

Run the suites your prompt names. Report the commands, pass/fail counts, reproducible failures with locations, and which causes are confirmed versus suspected. Make no production edits.

Start your report with `RESULT: PASS` only when every command your prompt names succeeded; `RESULT: FAIL` with the number failing, for example `RESULT: FAIL (3 failing)`; or `RESULT: BLOCKED` when you could not run them.
